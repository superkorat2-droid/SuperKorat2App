# แผน: ข้อความใต้ปุ่ม "ส่งแบบนิเทศ" ใช้ชื่อสำนักงานจากตั้งค่าเขต

> **สถานะ (11 พ.ย. 69): พักไว้ ยังไม่ได้ลงมือ** — ผู้ใช้สั่งเก็บแผนไว้ทำต่อที่บ้าน
> งานก่อนหน้าทั้งหมดขึ้น production แล้ว (ล่าสุด `f400b16`, migration 0101) · git สะอาด ไม่มีงานค้าง

## ที่มา
หน้าลิงก์สาธารณะ `src/views/SupervisionFillView.vue` บรรทัด ~880 พิมพ์ตายตัวว่า
"ข้อมูลจะถูกส่งให้กับ สพป. เพื่อประมวลผลต่อไป" ผู้ใช้อยากให้ดึงชื่อจากระบบ และเลือก **ชื่อสำนักงานเต็ม**
(หน้าโรงเรียนล็อกอิน `SchoolSupervisionFillView.vue` ไม่มีข้อความนี้ ไม่ต้องแก้)

## ที่มาของชื่อ
ใช้สูตรเดียวกับชื่อใต้โลโก้เว็บ (`areaShort` ใน `src/App.vue` บรรทัด ~37):
1. `area_config.tagline` ถ้ามี — production ตอนนี้ = "สำนักงานเขตพื้นที่การศึกษาประถมศึกษานครราชสีมา เขต 2"
2. ไม่มีก็ประกอบจาก `area_type` + `province` + `area_number` (เช่น "สพป. นครราชสีมา เขต 2")
3. ไม่มีอะไรเลย → "สำนักงานเขตพื้นที่การศึกษา"
หน้านี้โหลดตั้งค่าเขตอยู่แล้ว (`useAreaConfig` → `areaConfig`, เรียก `fetchConfig()` ใน `onMounted`) จึงไม่ต้องดึงข้อมูลเพิ่ม

ผลบนเว็บจริง: "ข้อมูลจะถูกส่งให้กับ สำนักงานเขตพื้นที่การศึกษาประถมศึกษานครราชสีมา เขต 2 เพื่อประมวลผลต่อไป"
ถ้าวันหน้าแก้ชื่อในหน้า "ตั้งค่าเขต" ข้อความนี้เปลี่ยนตามเอง

## งาน
- `src/views/SupervisionFillView.vue`: เพิ่ม computed `officeName` ตามสูตรข้างบน แล้วแทน "สพป." ในข้อความด้วย `{{ officeName }}`

## ไม่ต้องทำ
ไม่มี migration · ไม่แตะฐานข้อมูล · ไฟล์เดียว

## การทดสอบ
1. เปิดลิงก์สาธารณะของแบบในเครื่อง → ข้อความใต้ปุ่มขึ้นชื่อตาม `tagline` ของ local
2. แท็บ 👁 ดูตัวอย่างในหน้าแก้ไขแบบขึ้นเหมือนกัน
3. ล้าง `tagline` ใน local ชั่วคราว → ขึ้นชื่อที่ประกอบจากประเภท/จังหวัด/เขต → คืนค่าเดิม
4. `npx vite build` ไม่มี error → commit + push → รอ Vercel success
