## ทำอะไรไปบ้าง

### 1. แก้บั๊กร้ายแรง: กดบันทึกแบบนิเทศแล้วคำตอบหาย
- **สาเหตุ:** `save()` ใน `AdminSupervisionFormView.vue` เดิมลบคำถามทั้งฟอร์มแล้ว insert ใหม่
  แต่ `supervision_answers.question_id` เป็น `ON DELETE CASCADE` → คำตอบที่ส่งมาแล้วหายหมดทุกครั้งที่กดบันทึก
- **แก้:** อัปเดตข้อเดิม (id เดิม) / insert ข้อใหม่ / ลบเฉพาะข้อที่ผู้ใช้เอาออก
  ถ้าข้อที่ลบมีคำตอบอยู่ จะขึ้นคำเตือนให้ยืนยันก่อน
- หลังบันทึกโหลดใหม่ทุกครั้ง (ไม่งั้นแบบใหม่กดบันทึกซ้ำจะได้คำถามซ้ำ)

### 2. ปุ่มทำสำเนาคำถาม
- ไอคอนทำสำเนาบนการ์ดคำถามทุกข้อ (วางต่อท้ายข้อนั้น)
- ปุ่ม **"+ ทำสำเนาข้อก่อนหน้า"** ด้านล่าง
- ข้อที่สำเนามาใช้ไฟล์ภาพเดียวกัน → ลบภาพจะลบไฟล์จริงเฉพาะเมื่อไม่มีข้ออื่นใช้

### 3. ตำแหน่งชื่อแบบในหน้าปก (ชิดซ้าย / กึ่งกลาง)
- คอลัมน์ใหม่ `supervision_forms.title_align` ค่าเริ่มต้น `center` (แบบเดิมหน้าตาไม่เปลี่ยน)
- ใช้ทั้งหน้าลิงก์สาธารณะ (`SupervisionFillView.vue`) และหน้าโรงเรียนล็อกอิน (`SchoolSupervisionFillView.vue`)

### 4. แท็บ "👁 ดูตัวอย่าง" ในหน้าแก้ไขแบบ
- ใช้ `SupervisionFillView` ตัวจริงผ่าน prop `preview` → ตัวอย่างตรงกับของจริงเสมอ
- ไม่ต้องบันทึกก่อน · ไม่เรียก RPC · ไม่เก็บแบบร่าง · ไม่อัปโหลดหลักฐาน · กดส่งแล้วไม่บันทึกจริง

### 5. ผู้จัดการแก้คำตอบได้
- หน้าผลลัพธ์ → ตาราง "โรงเรียนที่ส่งแล้ว" → ปุ่ม **"ดู / แก้คำตอบ"**
- คอมโพเนนต์ใหม่ `src/components/supervision/SupervisionAnswerEditModal.vue`
- บันทึกเฉพาะข้อที่เปลี่ยน · เก็บ `edited_by` / `edited_at` · แสดงป้าย "✎ แก้ไขโดยผู้ดูแล (ชื่อ)"
- **ใครแก้ได้:** แอดมิน / ผู้สร้างแบบ / ผู้รับผิดชอบรายบุคคล (`responsible_ids`)
  ผ่านฟังก์ชัน `can_manage_supervision_form()` — **ไม่นับ `responsible_group`**
  เพราะแบบเก็บ key กลุ่ม แต่ `profiles.department` เก็บชื่อกลุ่ม จับคู่ไม่ได้แน่นอน

### 6. ปิดช่องโหว่ (อยู่ใน migration 99)
- เดิม: ผู้ล็อกอินทุกคน (รวมบัญชีโรงเรียน) insert คำตอบ/ชุดคำตอบเข้าแบบไหนก็ได้ และ staff ทุกคนแก้คำตอบได้ทุกแบบ
- ตอนนี้: insert/update ได้เฉพาะผู้จัดการแบบนั้น
- การส่งแบบไม่กระทบ เพราะ `submit_supervision_public` / `submit_supervision_authenticated` เป็น
  SECURITY DEFINER (ตรวจบน production แล้ว) — ทดสอบส่งผ่านลิงก์สาธารณะหลังปิดสิทธิ์ ผ่าน

## สิ่งที่ยังไม่ได้ทำ / ข้อจำกัด
- ยังไม่ได้ลองส่งแบบด้วย**บัญชีโรงเรียนจริง** (ใช้ RPC แบบเดียวกับลิงก์สาธารณะที่ทดสอบผ่านแล้ว)
- ลบหลักฐานในหน้าแก้คำตอบ = ตัดลิงก์ออก ไม่ลบไฟล์ใน Storage
- แท็บตัวอย่างแสดงหน้าตาแบบลิงก์สาธารณะ (หน้าโรงเรียนล็อกอินต่างกันเล็กน้อยตรงเลือกโรงเรียน)
- ถ้าอยากให้ "มอบทั้งกลุ่ม" แก้คำตอบได้ด้วย ต้องแก้เรื่อง key/label ของกลุ่มให้ตรงกันก่อน
